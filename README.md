# Cyber-JEV — project page

**[Visit the project page](https://ricardoz-kisara.github.io/cyber-jev/)** · **[Read the research manuscript](assets/cyber-jev-paper.pdf)**

Cyber-JEV studies matched contrastive fine-tuning of language models for source-code vulnerability triage. This repository contains the public research overview, reported evaluation results, citation information and manuscript PDF. The page supports English and Chinese.

## Availability

The research implementation, training code, model weights, datasets and private experiment records are not distributed in this repository. The project remains closed source. Publishing this presentation website does not grant an open-source license to the research implementation or the original materials.

## Publication status and evidence

The PDF is the eight-page research manuscript as revised in November 2026, after peer review. It replaces the October 2026 version and carries a new title. It is described as a manuscript, without asserting publication, conference acceptance or an arXiv identifier. Results concern offline historical benchmarks; a production deployment or discovery of new vulnerabilities is not claimed. Please consult the manuscript for the evaluation protocol, baselines and limitations.

## Website

A buildless static site served by GitHub Pages from the `main` branch, with four pages: overview, method, results and paper. It uses no external JavaScript dependencies, trackers or backend services. The browser interactions switch language (remembered across pages) and copy a citation. The illustrative workflow does not run model inference.
