A72 and P309 are external TitanVul suites. Training on patched-only groups scores higher on these pair tests, illustrating the trade-off between global ranking and patch sensitivity.

Evaluation separates protected splits from training by project, CVE, fix commit and code similarity. The manuscript reports project-cluster bootstrap intervals and patch-pair tests. Dataset labels and commit-derived supervision retain their original limitations.

A role in the review workflow

A first pass.
A human decision.

The intended use is to rank changed functions before deeper review with static analysis, rules or a security reviewer.

The work evaluates historical functions and fixes. Live pull-request deployment, new vulnerability discovery and comparative throughput have not been demonstrated. A score prioritizes attention; it does not establish that code is safe.
